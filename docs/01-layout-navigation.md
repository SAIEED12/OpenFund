# 01 — Layout & Navigation

## Layout Structure
Two primary structures: Basic Layout and Dashboard Layout. Dashboard layout is described in `docs/03-creator.md` through `docs/05-admin-challenges.md` (shell section).

## Navbar
Primary navigation tool.

### For Not Logged-in Users
- Website Name / Logo
- Explore Campaigns
- Login
- Register
- Join as Developer (redirects to client GitHub repository)

### For Logged-in Users
- Website Name / Logo (click redirects to home page)
- Dashboard
- Available Credits
- User Profile and Logout Button
- Join as Developer (redirects to client GitHub repository)

## Footer
Contains website logo and linkable social media icons redirecting to profile (LinkedIn, Facebook, GitHub, etc.).
